# FormLift

An experimental, local replacement for a small Typeform questionnaire, focused on preserving observed branching and backtracking behavior.

**Status: planning only.** Application code, source captures, compatibility results, benchmarks, and a release do not exist yet. The proposed implementation budget is 180 minutes with Claude Code and the operator's available Fable model.

The first deliverable is a real reference capture and an independently matching execution. A form renderer alone does not establish reverse engineering.

The planning proposal will live on the `docs/formlift-sdlc-plan` branch. Implementation starts in a later stage, after the evidence gate described in that proposal.
